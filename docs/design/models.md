# Real models (visual step-change)

Vic's verdict (2026-10-19): the visuals were weak because key objects were vanilla cubes with a
texture or flat sprites. This pass gives the visible machines, the boss and the worn circlet real
multi-part geometry, all modelled procedurally in the repo's own art pipeline
(`tools/art/mnart/*`, regenerated by `tools/art/build.py`) — the same way every other asset in the
mod is made. No third-party model or texture was downloaded or copied.

needed — Minecraft JSON models must be authored to the block grid anyway, and generating them in
the existing pipeline keeps `build.py --check` reproducible and the license story trivial. If
external assets are ever adopted, they must be CC0/CC-BY/MIT with source URL, author and license
recorded in this table and in `CREDITS.md` before merge.

## What changed

- **Hush loom**: cube → loom frame with a visible strung warp; the threaded state adds the woven
  band and cloth on the beam. Old cube face textures removed (the guide loom page now renders the
  real model via `block_quads`).
- **Ember brazier**: cube → legged bowl with an ember bed; the lit state glows from the bed.
  Guide brazier page likewise renders the real lit model.
- **Remembering circlet**: flat sprite in hand → 3D octagon band with a brow gem (own display
  transforms, not the lens/needle diagonal). Worn rendering (equipment texture) is unchanged.
- **Unremembered**: was the faded humanoid at 1.8x. Now its own `UnrememberedModel`: five splinter
  crown shards, shoulder pauldrons, a bigger heart shard and a robe skirt, on the existing
  texture/UV family (no texture or save change). Scar, Archive Keeper and Archive Guardian already
  have bespoke models (`ResidueModel`, `ArchivistModel`, `FadedModel` family) and were left alone.
- Chronicle lens and extraction needle already had 3D in-hand models; audited, unchanged.
- The observatory is a structure whose centrepiece is the composition reel (already modelled).

Element counts stay small (tens per block), textures reuse the 64x64 packed sheets, and no
protocol, save or recipe data changed.
